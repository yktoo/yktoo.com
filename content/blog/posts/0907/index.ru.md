Вышел **Comentario** [**3.19.0 Maghera**](https://gitlab.com/comentario/comentario/-/releases/v3.19.0), а с ним вебхуки, журнал аудита и полностью *доступный* (совместимый со вспомогательными технологиями) виджет комментариев.

[Comentario](/software/comentario) — это быстрый и мощный свободный сервер комментариев для веб-страниц, написанный на {{< fl "Go" >}}.

## ИИ на марше

Об одной вещи стоит сказать особо.

Это первая версия, разработанная при активном участии ИИ ({{< fl "Claude Code" >}}). Сильно переживать не стоит: весь сгенерированный код дотошно проверяется и исправляется мной (пока ещё человеком). Это требует множества итераций (планирование, уточнение, реализация, потом всё повторить опять) но в целом я **очень** доволен результатами такого сотрудничества. Это колоссально ускорило разработку и позволило мне создавать гораздо более функциональные решения, не увязая в болоте всё более сложной внутренней механики {{< fl "Comentario" >}}: достаточно хотя бы взглянуть на объём [изменений с прошлого релиза](https://gitlab.com/comentario/comentario/-/compare/v3.18.0...v3.19.0?from_project_id=42486427).

### Тосты стали уведомлениями

Самое заметное изменение в админке — тосты (сообщения, которые всплывали в углу экрана и через несколько секунд исчезали) теперь заменены уведомлениями ({{< fl "notices" >}}, [!38](https://gitlab.com/comentario/comentario/-/merge_requests/38)).

Уведомление появляется там, где оно уместно: на странице, к которой относится, глобально в Центре управления или — если что-то требует немедленного внимания — в модальном диалоге. Страница автоматически прокручивается, чтобы ошибки и предупреждения появились в поле зрения; закрытое уведомление остаётся скрытым для данного пользователя.

{{< imgfig "https://res.cloudinary.com/yktoo/image/upload/v1792225177/blog/bb53n21rod8cczjuuqt5.png" "Пример уведомления об ошибке." "border shadow" >}}

Для рутинных подтверждений сообщение больше вообще не нужно: после успешного выполнения действия на только что нажатой кнопке ненадолго появляется галочка:

{{< video "https://res.cloudinary.com/yktoo/video/upload/v1792225519/blog/lf1mpmeris7esmc65qct.mp4" "autoplay loop muted" "16x9" >}}

Уведомления также сообщают о выходе новой версии {{< fl "Comentario" >}}, а количество ожидающих уведомлений админки отображается на кнопке пользователя в верхней навигационной панели.

{{< imgfig "https://res.cloudinary.com/yktoo/image/upload/v1792225049/blog/lwtfamejb6o97ovztbkd.png" "Уведомление о доступном обновлении." "border shadow" >}}

### Вебхуки

Теперь {{< fl "Comentario" >}} умеет оповещать ваши собственные сервисы о происходящем на домене при помощи [исходящих вебхуков](https://docs.comentario.app/en/kb/webhooks/) ([#152](https://gitlab.com/comentario/comentario/-/issues/152)). Всякий раз, когда комментарий создаётся, изменяется, удаляется, одобряется или отклоняется, {{< fl "Comentario" >}} отправляет `POST`-запрос с {{< fl "JSON" >}}-описанием события на указанный вами {{< fl "URL" >}}.

Таким образом {{< fl "Comentario" >}} становится источником событий для остальной вашей инфраструктуры: новый комментарий может попасть в чат, запустить пересборку статического сайта или пополнить вашу собственную очередь модерации, в пуш-режиме (без необходимости постоянно опрашивать {{< fl "API" >}}).

{{< imgfig "https://res.cloudinary.com/yktoo/image/upload/v1792222560/blog/zgia4q7wk271vszerfyt.png" "Свойства вебхука." "border shadow" >}}

Вебхуки регистрируются для каждого домена его владельцем, с помощью новой кнопки **Webhooks** в свойствах домена. Каждый вебхук получает собственный *секретный токен* для проверки подписи, а при помощи тестовой отправки (`ping`) можно сразу увидеть, доступен ли ваш эндпоинт и правильно ли принимает ли он сообщение от {{< fl "Comentario" >}}. Персональные данные комментаторов (емэйл, {{< fl "IP" >}}-адрес, страна) никогда не включаются в отправляемые данные.

{{< imgfig "https://res.cloudinary.com/yktoo/image/upload/v1792222713/blog/gzpy7fs6mi02opbfssg5.png" "Подробности доставки вебхука." "border shadow" >}}

### Журнал аудита

Новый журнал аудита ([Audit log](https://docs.comentario.app/en/kb/audit-log/)) фиксирует различные действия пользователей и системы на сервере: кто вошёл в систему (или безуспешно пытался), кто изменил настройки домена, кто модерировал комментарий, кто заблокировал пользователя и так далее.

{{< imgfig "https://res.cloudinary.com/yktoo/image/upload/v1792223030/blog/ieh1nje4v8uwwe4l9oxq.png" "Журнал аудита." "border shadow" >}}

Записи в журнал могут только добавляться; по истечении [срока хранения](https://docs.comentario.app/en/legal/privacy/#addendum-i-data-cleanup-policy) они автоматически удаляются. Персональные данные пользователя вычищаются из журнала при [удалении его учётной записи](https://docs.comentario.app/en/legal/account-removal/) в соответствии с требованиями {{< fl "GDPR" >}}.

Записи можно фильтровать по множеству критериев: типу объекта, действию, результату, методу аутентификации, идентификатору {{< fl "Correlation ID" >}} (он группирует связанные записи и позволяет легко сопоставить сообщённую ошибку с тем, что происходило на сервере) и другим.

{{< imgfig "https://res.cloudinary.com/yktoo/image/upload/v1792223279/blog/j4lxhvxjc7rtgfeefwfy.png" "Журнал аудита с применённым фильтром." "border shadow" >}}

### Доступность

В продолжение работы, начатой в [3.18.0](0906), доступность ({{< fl "accessibility" >}}) встраиваемого виджета комментариев была улучшена ещё больше; начальную работу выполнила {{< fl "Georgiana Frincu" >}}. Все проблемы с цветовым контрастом теперь устранены ([#234](https://gitlab.com/comentario/comentario/-/issues/234)), а виджет [соответствует требованиям WCAG 2.2 уровня AA](https://docs.comentario.app/en/about/features/embedded/#accessibility), что автоматически проверяется при помощи библиотеки [{{< fl "axe" >}}](https://github.com/dequelabs/axe-core) в тестах.

### Поддержка TLS и Unix-сокетов

До сих пор {{< fl "Comentario" >}} работал только по обычному {{< fl "HTTP" >}}, оставляя {{< fl "SSL termination" >}} обратному прокси (или аналогичному компоненту). Теперь он может также [принимать соединения](https://docs.comentario.app/en/configuration/backend/static/#listener) непосредственно по {{< fl "HTTPS" >}} или через доменный сокет {{< fl "Unix" >}} ([#233](https://gitlab.com/comentario/comentario/-/issues/233)), что задаётся новым параметром `scheme`:

```bash
comentario --scheme=unix --socket-path=/run/comentario/comentario.sock --socket-perms=0660
```

Сокет удобен, когда обратный прокси работает на том же хосте: на сервере не занимается {{< fl "TCP" >}}-порт, а доступ регулируется правами на файл. Схема {{< fl "HTTPS" >}} предназначена для конфигураций вообще без декодирующего {{< fl "TLS" >}}-трафик прокси. Имейте в виду при этом, что {{< fl "TLS" >}}-сертификат загружается только при запуске сервера.

### Прочие изменения

* Для домена и страницы учитываются только одобренные и неудалённые комментарии ([#203](https://gitlab.com/comentario/comentario/-/issues/203))
* Встраиваемая часть: исправлено состояние гонки в {{< fl "Live update" >}}, из-за которого «воскресали» удалённые комментарии или возникал конфликт с изменениями собственного комментария
* Админка: галочки отображаются с переведённым текстом для скрин-ридеров
* Админка: свойства пользователя: элементы списка ролей в доменах теперь ведут на пользователей домена, а не на сами домены
* Бэкенд: исправлена проверка конфигурации {{< fl "SSO" >}} домена; унифицирована проверка {{< fl "URL" >}}
* Бэкенд: `EmailFrom` теперь может содержать имя в не-{{< fl "ASCII" >}}-кодировке
* Бэкенд: более надёжная локализация; сброс кэшей атрибутов при сбросе БД
* Плагины: экспериментальный {{< fl "API" >}} плагинов расширен аудитом, хранилищем «ключ-значение», отправкой почты, локализацией, уведомлениями, подтверждениями, событиями
* {{< fl "Helm" >}}: добавлена схема для значений и настройка вебхуков; чарт теперь официально имеет версию 1.0.0
* Документация: добавлены описание журнала аудита и заметки о соответствии {{< fl "WCAG" >}}
* {{< fl "E2e" >}}-тесты: покрытие {{< fl "API" >}} встраиваемой части, интерактивный тест {{< fl "SSO" >}} в безголовом режиме
* Обновление инструментария и зависимостей ({{< fl "Go" >}} 1.27.2, {{< fl "Yarn" >}} 4.18). Для компиляции {{< fl "Comentario" >}} теперь *требуется как минимум* {{< fl "Go" >}} 1.27.
